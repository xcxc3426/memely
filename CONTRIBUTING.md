# Contributing

Read [methods](METHODS.md), [curation](CURATION.md) and [source scope](SOURCES-AND-SCOPE.md) before changing the pipeline. Keep observations, lexical assignments and model interpretation distinct.

Test meaningful boundaries: adjacent windows, zero baselines, delayed or stale activity, source-ID ambiguity, exact duplicate scope, multiple theme assignments and citation membership. A model's fluent answer is not evidence that a new source record exists.

New importers should preserve the original response, collection scope, source clock, measurement unit and missing-data state. Explain how community and pool identities are established. Avoid turning a signature count into a holder or person count.

Regenerate derived outputs and offline HTML after source changes. Regenerate affected figures, inspect the result, run checks, then refresh the package manifest. Preserve the flat upload layout and all root-relative image paths.
