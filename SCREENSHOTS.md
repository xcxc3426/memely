# The complete culture desk

All twelve research views are 1600 × 1100 PNGs. The cover is 1600 × 800. They use the reference cutoff at 12:00 UTC on 2 November 2026 and the default six-hour window. The selected theme is Night shift.

`capture.mjs` renders application drawing code directly, checks text against the outer image bounds and writes PNGs. These are numerical application figures, not browser captures or screenshots of an AI provider's product.

The app's Save view action exports its current Canvas. Keep example and connection labels visible when sharing the reference edition. All exact values, text and diagrams come from code; the decorative mascot is the separately generated asset.
