# Open the culture desk

Extract the ZIP and open `Memely.html`. It embeds the code, source corpus and mascot. The default edition is a fixed example cutoff of 12:00 UTC on 2 November 2026 with a six-hour window.

## A useful first pass

1. Open Narrative map and select a theme through its left-hand node or the selector.
2. Read the matching posts in Source reader and the text alternative beneath the figure.
3. Open Attention windows and compare equal adjacent intervals.
4. Open Solana context. Nap Club is deliberately stale at the default cutoff.
5. Export Research JSON, Local brief or Receipt JSON.

The reference Night shift result is 11 current retained original posts, three prior posts and five community aliases. All source records are authored examples with origin labels.

## Use your own source material

Add a source post through the form, choosing an existing community alias. It is recorded as a user-supplied original. The new body is tested against the existing theme definitions. Adding to the example corpus changes its envelope origin to mixed.

For different themes, communities or activity measurements, import a complete validated corpus. The file input limit is 2 MiB. Invalid imports preserve the active copy. The browser saves one active corpus under `memely.corpus.v1`; export a backup before replacing it or opening the reference edition again.

## Source edition

Run `npm start` and open `http://127.0.0.1:4175`. `index.html` loads modules and JSON through that server. `Memely.html` is the separate local-file route.

## Optional interpretation

Opening the desk makes no model call. Configure the CLI only when you want to send a prepared source packet to your xAI account. [AI setup](AI-SETUP.md).
