# Memely artwork and figure provenance

## Selected final mascot

`memely.png` is an original generated Shiba Inu illustration created on 2 November 2026 with the built-in image-generation tool. It follows the user's requested classic Doge meme direction: tan/cream pixel art and a recognisable side-eye expression. No specific source photograph or existing sprite was supplied. The original selected raster is included without edits.

The final mascot is used in the README, cover, application masthead and research-role view. Decorative character art does not encode a source observation or numerical measurement. It is independent of any token's logo or provider identity.

## Exact selected prompt

Use case: logo-brand. New final mascot for Memely, a Solana meme-culture research project. The user wants familiar classic internet meme energy in the Doge / Shiba Inu direction, not an invented abstract creature. Create an original very readable 8-bit pixel-art Shiba Inu head and a little neck, three-quarter portrait facing slightly right, tan-orange fur, cream cheeks and muzzle, two pointed ears, dark brown pixel outline, round dark eyes glancing sideways with raised asymmetrical eyebrows, tiny knowing closed-mouth smile. Expression: the iconic bemused, suspicious, lovable internet dog side-eye, immediately recognisable as a Shiba meme mascot. No body or hands, no accessories, no clothes, no shell, no crab, no reporter props, no symbols. Pixel style: authentic 8-bit sprite on about a 64x64 logical grid, crisp large square pixels, hard stair-step contours, simple flat clustered shading, very limited orange/tan/cream/dark-brown palette. Clean centered square composition with generous margins on a solid cool-white #fcfcff background. No text, no letters, no labels, no typography, no coins, no chain logos, no charts, no frames, no scenery, no watermark. No realistic fur, no smooth vector edges, no gradients, no 3D, no glow, no soft shadow. It should look like a polished classic meme sprite, friendly and cool at GitHub avatar size. New original illustration, not a copy of a specific existing photograph.

## Numerical figures

`capture.mjs` composes twelve 1600 × 1100 application figures and a 1600 × 800 cover. All text, counts, maps, bins, tables, digest strings and scope labels are drawn by code using the same renderer as the local interface. The only image-model asset in the package is the selected Shiba portrait.

The reference corpus is authored example material. Its labels do not identify actual accounts, posts, token launches or provider results. The screenshots are not images of X or a model provider's app.
