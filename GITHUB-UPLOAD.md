# Upload the full culture desk

Every project file is at the root of one flat **memely** folder. The logo, cover and twelve numbered PNGs sit beside `README.md`.

1. Extract `Memely-GitHub.zip` and open the inner `memely` folder.
2. Create a repository under your chosen account named **memely**. Leave automatic README, license and ignore-file generation off because they are supplied.
3. Choose **Add file → Upload files**.
4. Select all files inside the extracted folder with Ctrl+A, then upload the selection.
5. Confirm that `README.md`, `memely.png`, `memely-cover.png` and all twelve numbered PNGs are at the root, without an extra parent directory.
6. Commit the upload with the title below.
