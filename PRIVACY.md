# Source material and account boundaries

The browser stores one active corpus in local storage when available. It contains no analytics, remote font requests, API key field, model request, social login or wallet call. Source mode fetches local project files; the standalone edition embeds them.

Local storage is not encrypted and can be cleared. Export the corpus as a portable backup. Opening the reference edition replaces the active browser copy; it does not remove previously downloaded files.

Research exports include original source text, aliases, references and supplied activity measurements. An explicit AI CLI request sends that selected packet to the provider. Review your input before that action. The adapter requests `store: false` for response retrieval; this does not constitute a blanket data-retention guarantee beyond the provider's policies.

Keep keys in the environment and private source material outside a public GitHub upload. The supplied release contains authored example records and no account credential.
